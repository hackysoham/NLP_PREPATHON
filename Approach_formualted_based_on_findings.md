# Findings & Approach — One-Page Mid-Term Report
**Agentic Customer 360 — Proactive Intervention Desk | Prepathon 2026, ITM 15.0**

## What I found in the domain
Three things stood out reading around this problem before writing any code. First, "agent memory" is not one thing — MemGPT (Packer et al., 2023) and Generative Agents (Park et al., 2023) both converge on a *tiered* design (a small always-in-scope working set, plus a larger retrievable store), but Generative Agents adds the detail we found most load-bearing for a churn/upsell use case: retrieval should be scored on recency, importance, *and* relevance together, not similarity alone, because an important-but-older signal (a past fraud hold) shouldn't be crowded out by a recent-but-trivial one. Second, multi-agent coordination is not a single pattern to pick once — Anthropic's *Building Effective Agents* gives a working vocabulary (chaining, routing, parallelization, orchestrator-workers, evaluator-optimizer) that different pipeline stages genuinely need different members of, and the debate literature (Du et al. 2023; Liang et al. 2023) is specific about *when* debate helps (genuinely opposed incentives on the same evidence) versus when it doesn't reliably beat cheaper methods (Smit et al., 2024) — which argues against using debate as a default disagreement-resolution mechanism everywhere. Third, the "ambient, not chatbot" framing in the PS has real production precedent: Uber's Michelangelo and DoorDash's real-time feature work both treat streaming feature freshness as the actual operational bottleneck, not model quality — and the same is true for retrieval freshness once you're citing policy documents that can change mid-conversation.

## My approach
I am  building the system as a five-stage pipeline behind one deterministic, non-LLM hard-guardrail fast path (legal/fraud keyword match → immediate human legal escalation, bypassing every agent). Inside that boundary: **(1)** a swarm of independent ingestion agents (Usage, Support, Transaction, KYC) writing only structured conclusions — never raw reasoning traces — to a shared per-customer state board; **(2)** a three-tier memory hierarchy (working / episodic / semantic) on that board, with the life-event inference persisted as long-lived state that other agents read rather than a one-off classification; **(3)** a deliberation layer where a Retention agent and an Upsell agent are explicitly prompted to *disagree*, arbitrated by a separate Synthesis agent — debate is scoped to just this one point in the pipeline, deliberately, because my reading suggests debate-everywhere is not empirically justified; **(4)** a round-robin drafting pass followed by a critique-refiner check against an explicit written rubric, with rejections stored as structured reflections (à la Reflexion) so repeat mistakes are visible in the audit trail; and **(5)** a deterministic (not LLM-judged) routing rule to either automated dispatch or a human-in-the-loop dashboard, gated on cost, confidence, *and* unresolved agent disagreement independently of dollar amount.

The bounded action set from PS §3 (no-action, retention outreach, RM escalation, personalized offer, support intervention, compliance hold) is what every path through the pipeline terminates in — I treated "must decide, not just monitor" as the hard constraint shaping every other choice, including why I did not build a chatbot-style always-on assistant layer on top: every agent here is ambient by construction (event-, time-, or agent-dependent triggers only), matching PS §1.3.

## What I'm still deciding
Two things I've deliberately left open rather than guessed at: (a) whether swarm correlation should become an explicit dependency graph once I add agents beyond the initial my (leaning toward "not yet" — flat fan-out is simpler and I don't have a second correlation case to design against), and (b) the exact decay function for episodic memory importance scores, which I plan to tune empirically against the practice scenarios once the scoring harness exists, rather than fixing a half-life constant now on guesswork.
